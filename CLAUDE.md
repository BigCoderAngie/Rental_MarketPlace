## Styling

Always use the theme colours defined in `src/app/globals.css` (`bg-brand`, `text-muted`, `border-line`, `bg-gold-soft`, `text-danger`, ...), never Tailwind's built-in palette (`zinc`, `emerald`, `amber`, `red`, ...). Marigold (`gold`) is a fill only: never use it for text; use `text-gold-ink` for warning text. Keep `danger` (terracotta) for overdue, problems and errors.
